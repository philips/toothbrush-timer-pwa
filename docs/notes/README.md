# Original design notes

These are the handwritten Supernote pages (`toothbrush-pwa.note`) that this
app was built from, exported as images and a searchable PDF.

- [`page-1-tech-stack-basic-usage.png`](./page-1-tech-stack-basic-usage.png) —
  tech stack (static HTML + PWA, GitHub Pages, mobile/tablet) and basic usage
  (duration picker defaulting to 2:00, Start button).
- [`page-2-brushing-segments.png`](./page-2-brushing-segments.png) — the six
  brushing segments (Upper/Lower × Front/Back/Top) and the teeth illustration
  concept with per-segment time remaining.
- [`page-3-segment-definitions.png`](./page-3-segment-definitions.png) — the
  precise visual definition of each segment: every arch is drawn as a
  "tunnel" cross-section with an **outer rim** (lip/cheek-facing surface)
  and an **inner rim** (tongue-facing surface). Highlighting the outer rim
  = Front, the inner rim = Back, and the connecting band between them =
  Top (chewing surface). This page superseded an earlier, more ambiguous
  visualization attempt.
- [`toothbrush-pwa-notes.pdf`](./toothbrush-pwa-notes.pdf) — original
  searchable PDF export of all three pages.
